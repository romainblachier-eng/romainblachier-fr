# Portrait presse

`romain-blachier-portrait.jpg` est le fichier servi par les pages `/presse` et
`/en/press` (lien « télécharger le portrait »).

Format actuel : 724 × 1086 px, portrait. Convient à un usage web éditorial.
Pour un tirage papier, une rédaction demandera le fichier d'origine du
photographe (≥ 2000 px de large) — à fournir alors directement, ou à déposer ici
en remplacement.

Si le fichier est remplacé, garder **exactement le même nom** : les deux pages
Presse pointent dessus.
